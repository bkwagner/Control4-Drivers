Jellyfin (Universal)

Universal mini-app driver for launching Jellyfin on a connected TV or streaming device.

How it works

This driver does not launch anything by itself. It publishes a service ID for each supported platform and passes commands through to the TV or streamer driver it is bound to, which performs the launch using its own protocol.

PlatformService ID
UM_SONY_TVJellyfin — the app title as the TV reports it
UM_NV_SHIELDorg.jellyfin.androidtv — the Android package name

Installation

  1. Add the driver to the project.
  2. In Connections, bind its Jellyfin mini-app connection to a free RF_MINI_APP input on the TV or streamer driver.
  3. The app appears in Navigator for any room whose video path includes that device.

If it stops working

The usual cause is the app being renamed. On Sony Bravia the service ID must match the app's title exactly as the TV reports it; that is what broke the stock HBO driver when “HBO” became “HBO Max”. The current list can be read from the TV:

POST http://<tv-ip>/sony/appControl with {"method":"getApplicationList","params":[],"version":"1.0","id":1}

Then update JSON_APP_DATA at the bottom of driver.lua to match.

Icons are placeholders. They are a plain gradient, not the Jellyfin logo. To use real artwork, replace the PNGs under www/icons/ at the same paths and pixel sizes, then rebuild.
Auto-update is off. This is not a Control4-published driver, so there is nothing to update from. Leaving it off also prevents a published driver of the same name from replacing it.
