WarmlyYours (OJ Cloud)

Connects Control4 to WarmlyYours Wi-Fi floor-heating thermostats through the OJ Microline cloud at mythermostat.info, the same account the OJ Microline phone app uses. This is the account driver: it signs in, finds every thermostat on the account, and keeps them updated. Each thermostat then appears in Control4 through a WarmlyYours Thermostat (OJ Cloud) driver.

It replaces the annex4 WarmlyYours nSpire drivers. Those depended on annex4's own relay service for live updates, and that service no longer exists, so their temperatures went stale. This driver talks to the thermostat cloud directly.

Not affiliated with or endorsed by WarmlyYours, OJ Electronics or Control4.

Requirements

  • Control4 OS 3.3.0 or later, with internet access from the controller.
  • The thermostats set up in the OJ Microline app. To confirm the account works, sign in at https://mythermostat.info with the same email and password.

Setup

  1. Add WarmlyYours (OJ Cloud) to the project. Only one is needed per account.
  2. Enter the account Email and Password. Within a few seconds Login Status should read Logged In and Driver Status should show how many thermostats were found.
  3. For each thermostat, add a WarmlyYours Thermostat (OJ Cloud) driver to its room.
  4. On the Connections tab, bind each thermostat connection on this driver (named after the room set in the app) to a WarmlyYours Thermostat (OJ Cloud) driver.

How updates work

  • The driver keeps a notification request open to the cloud, so setpoint and mode changes made in the app or at the thermostat show in Control4 within seconds.
  • The thermostat reports its floor temperature to the cloud about once a minute, so that is how often the temperature in Control4 moves.
  • Changes made in Control4 are sent to the cloud and retried until the cloud confirms them. The cloud can take several seconds to apply a change.

Properties

PropertyDescription
EmailThe mythermostat.info / OJ Microline app account email.
PasswordThe account password.
Login StatusRead-only. Logged In, or the reason sign-in failed.
Driver StatusRead-only. Connection state and number of thermostats.
Driver VersionRead-only. Upstream release this build is based on.
Log LevelDetail of logging. Default 3 - Info.
Log ModeWhere logs go: Off, Print (Lua output window), Log or both. Turns itself off after 3 hours.

Actions

Refresh Thermostats

Re-reads the account. Use this after adding a thermostat in the app.

Reconnect

Signs out and back in without touching bindings or programming. Use this if the driver looks stuck.

Reset Driver

Removes every thermostat connection, which deletes their bindings and any programming that uses them.

Signs out and rediscovers from scratch. Only needed if thermostats were removed or renamed.

Troubleshooting

  • Login fails: sign in at https://mythermostat.info with the same details. If that fails too, the email or password is wrong.
  • Thermostat shows offline or stops updating: check the thermostat shows as online in the OJ Microline app. If the app can't reach it either, the thermostat has lost Wi-Fi.
  • Anything else: set Log Mode to Print, run Reconnect, and read the Lua output window.

About this build

This is the open-source Finite Labs Schluter DITRA-HEAT driver, v20260816 (github.com/finitelabs/control4-schluter), configured for WarmlyYours. Schluter DITRA-HEAT and WarmlyYours thermostats run on the same OJ Microline cloud, so only the cloud address and brand ID differ.

  • Automatic updates are removed on purpose. An update from the upstream project would install the Schluter version and point the driver at Schluter's cloud.
  • To rebuild from a newer upstream release, run tools/build_drivers.py in the WarmlyYours project folder.
